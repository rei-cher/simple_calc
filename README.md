# Instruction
## 1. Build
Run the build script
```
./build.sh
```
## Execute
To execute the program navigate to the 'build' directory and run 'simplecalc' with desired parameters
```
cd build
./simplecalc <number> <operator> <number>
```
#### Note: Arithmetic operators: + - * / % and Bitwise operators: & | ^ << >> <<< >>>
### Test Cases
For test case execution, from the parent folder (`./simple_calc/`) run test cases script
```
./test_cases.sh
```
